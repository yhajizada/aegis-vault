# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Nexus team takes security seriously. If you discover a vulnerability or security risk, please follow responsible disclosure:

1. **Do not** file a public issue on GitHub.
2. Send a detailed report describing the vulnerability, proof of concept, and affected versions to `security@nexus-template.org` (or open a private security advisory on GitHub).
3. We will acknowledge receipt of your vulnerability report within 48 hours and provide a regular status update on the patch.

Thank you for helping keep our users safe! 🛡️
